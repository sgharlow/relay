## The two steps that are manual on purpose

Not tedium left undone — both are load-bearing, and automating either would break what it protects.

- **The four-word call.** Two humans comparing a fingerprint out loud is the control that stops
  somebody who intercepted an invitation from being marked verified. **Until you make it, their
  answer does not count toward opening anything.** If the words do not match, do not mark them —
  use *"the words do not match"* in the same panel, which removes them, cancels the code and returns
  them to not-yet-invited so you can start again on a channel you trust.
- **Sending the owner arm.** That arm exists *because* you deliver it out of band. Automating the
  send converts it into the email arm — the channel measured broken on 2026-08-11 and the whole
  reason the standby architecture exists. Phase 0 measures the difference between the arms;
  collapsing them destroys the thing being measured.

## Two cautions

⚠️ **The claim code is readable exactly once**, at issue — only a hash is stored. The script captures
every code into `.relay-cohort-codes.json`, and that file is then **the only copy**. Do not delete it
before the codes are sent and claimed.

⚠️ **Email arm is capped at 20 per owner per rolling 24 hours** (`lib/notify/invite-budget.ts`). The
script refuses a run that would exceed it rather than half-sending. Owner-arm invitations send no
email and are unaffected.

## Why this matters more than it looks

Two shipped security decisions rest on the number this produces. Principle 1 of the standby
architecture is **conditional on claim conversion**, and adaptive minting assumes verifiers actually
reach `confirmed`. Both are live. The threshold is pre-recorded in `scripts/phase0-report.ts` so it
cannot move after seeing the result: **below roughly 50%**, the fallback path carries more traffic
than the primary one and the ranking swings back toward durable artifacts.

Twenty invitations is a directional read, not a decisive one — the same limitation that was ratified
for G1.
