## 6. Debt created

1. **🔴 CORRECTED — this was not benign debt; it was a reachable false-assurance path, and it is
   now fixed (`a5b91be`).** As originally filed, this entry read: *"Of three write paths only
   create declares `secret_kinds`… an honest answer rather than a wrong one — nothing is
   misreported."* **The post-sprint review proved that wrong in two ways.** First, the count was
   1-of-**five**, not 1-of-three (import, in-place update, and both onboarding flows all missed it).
   Second, and decisively, the **update path was not honest-but-empty**: `updateItem` re-encrypts in
   place and never rewrote `secret_kinds`, so editing a TOTP seed away left the old declaration
   `password,totp` standing over a blob that no longer held it — the item kept reading `usable` on a
   code it could not produce. That is a *misreport*, and worse than the original falsehood, because
   `unknown` prompts a question while a stale `usable` asserts a false answer. Because the sprint
   branch was never deployed (production predated Phase 1), there was no corrupt data and no exposed
   user — so it was reclassified from deferred debt to **part of S2's definition of done** and fixed
   on the branch before merge, in three structural layers (derive-at-choke-point, fail-closed
   boundary, enumerating guard), live-proven 15/15. **The lesson is the miscount itself:** I had
   just spent an iteration on this feature and written a "wiring" test, and still enumerated the
   call sites wrong by two. A guard that checks one call site is a guard on that call site; the fix
   is `lib/ops/secret-kinds-on-every-write.test.ts`, which enumerates every producer.
2. **Existing items stay `unknown` permanently unless re-saved.** Structural, not a bug: the server
   cannot read ciphertext, so nothing can ever backfill what an item holds. Stated in the use-case
   doc's limits. D3 is the mitigation.
3. **`verify:factors` is a fifth non-CI walk.** It needs `.env.local` and a running server like the
   others, so it inherits the same "somebody must remember" weakness `verify-scripts-documented`
   exists to bound. Documented in CLAUDE.md; no separate item filed.
